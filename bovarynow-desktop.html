HOW TO USE

SIMPLE. ALWAYS READY.

No installer. Run once and it stays in your system tray.

01

Run the shortcut

Run the BovaryNow.exe shortcut once. The panel appears on screen; the icon stays in the system tray.

02

Close without quitting

Click the X → hides to the tray (does not close the app). Click the tray icon → reopens the app.

03

No installation

No install required. The app creates a desktop shortcut after the first run and runs in the background via the system tray.
